### 💰 Excel-Based Finance Analytics Dashboard

### 🔍 Project Overview
This project focuses on analyzing AtliQ Hardware's financial performance using Excel. It provides Profit and Loss (P&L) reports by fiscal year, month, and market. The reports help track net sales, cost of goods sold (COGS), gross margin, and gross margin percentage to understand business performance

### 🎯 Objectives
1. Analyze financial performance across fiscal years.
2. Track monthly sales, costs, and gross margin.
3. Compare financial performance across different markets.

### 📌 Key Insights & Techniques
* Analyzed Net Sales, COGS, and Gross Margin.
* Compared financial performance across fiscal years.
* Examined monthly sales and gross margin trends.
* Compared Gross Margin % across different markets.

### 💼 Business Value
This project helps businesses:
* Understand sales and cost trends.
* Track profitability across different markets.
* Identify changes in Gross Margin %.
* Make better business decisions using financial data.
